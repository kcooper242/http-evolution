About

Student introduction

My name is Kennedy Cooper Jr., and this website was created for IT 3203 Web Development. It builds on my Assignment 1 research about the evolution of HTTP.

The purpose of the project is to explain HTTP in a clear way, from the basic request-and-response cycle to the changes introduced by HTTP/2 and HTTP/3.

Project goals

  • Present technical information in a clear, organized website.
  • Use HTML to structure content and CSS to create a consistent visual style.
  • Explain key changes in HTTP versions and why they matter.
  • Expand the website in later milestones with a JavaScript quiz and responsive improvements.
